# Бот наличия: следит за размерами у поставщиков

Telegram-бот для тех, кто продаёт вещи поставщиков (дропшиппинг на Авито и не только).
Он читает вашу таблицу с выставленными вещами и таблицы наличия поставщиков и пишет вам,
когда у поставщика по вашей вещи что-то изменилось:

```
🔔 NORD — изменения

Пуховик Zara черный nord
➖ Убрали: M, XL
Сейчас: S, L, XXL

Пуховик Hugo Boss синий nord
🚫 Закончилась — размеров больше нет
Сейчас: нет в наличии
```

Ещё он умеет искать по всей базе поставщиков — чтобы подобрать, что выставить следующим.
Просто напишите боту:

- `куртки s m l` — куртки, у которых есть все три размера сразу. «Куртки» — это и пуховики,
  и ветровки, и бомберы; так же работают «кофты», «штаны», «обувь»;
- `s m l` — любые вещи с такими размерами;
- `пуховик zara` — поиск по названию;
- `худи xl vega` — худи размера XL у поставщика VEGA.

В ответе — название вещи, размеры, цена и магазин. Вещи, которые уже есть в вашей таблице
(в любом статусе), в поиске скрыты: бот показывает то, чего у вас ещё нет. Под ответом есть
кнопка «Показать вместе с моими».

## Как он понимает, что откуда

В вашей таблице поставщик указан в названии вещи: «Пуховик Zara черный **nord**»,
«Пуховик Champion белый **VEGA**». Когда вы добавляете таблицу поставщика, бот спрашивает,
какой пометкой этот поставщик обозначен, и дальше сам находит пару по названию:
«Пуховик Zara черный nord» → «ПУХОВИК ZARA ЧЕРНЫЙ» в таблице NORD.

- Следит только за вещами со статусом «выставлен». Сняли или продали — перестаёт,
  выставили новую — подхватывает сам при следующей проверке.
- Если уверен в паре — сразу начинает следить и показывает, что с чем связал.
- Если вариантов несколько («Пуховик Moncler» при четырёх разных Moncler у поставщика) —
  один раз спрашивает кнопками, какая это вещь.
- Ошибся — «📦 Мои вещи» → «🔧 Исправить привязку».

## Что нужно

Компьютер, который включён постоянно, и интернет. Подойдёт Mac (macOS 12 Monterey и новее,
Intel или Apple Silicon), Windows 10/11 или Linux.

Сначала **создайте бота**: в Telegram откройте `@BotFather` → `/newbot` → придумайте имя →
скопируйте токен (строка вида `123456789:AAH...`). Он понадобится при первом запуске.

## Запуск на Mac (macOS 12 и новее)

1. **Установите Python 3.13**: откройте <https://www.python.org/downloads/macos/>, скачайте
   «macOS 64-bit universal2 installer» для версии 3.13 и установите как обычную программу.
   (Подойдут версии 3.11–3.13. Если у вас есть Homebrew — `brew install python@3.13`.)
2. **Скачайте папку `stock-bot`** и положите её в домашнюю папку — туда, где лежат «Загрузки»
   и «Документы», но не внутрь них.
3. **Запустите бота.** Откройте программу «Терминал», наберите `bash`, пробел, затем перетащите
   файл `start.command` из папки в окно Терминала и нажмите Enter. Должно получиться примерно так:

   ```
   bash /Users/вы/stock-bot/start.command
   ```

   При первом запуске скрипт сам установит всё нужное (пара минут) и попросит вставить токен.
   В следующие разы достаточно дважды кликнуть по `start.command`.
4. Откройте своего бота в Telegram и нажмите **«Старт»**. Кто первый нажал — тот и владелец,
   остальным бот не отвечает.

Окно Терминала должно оставаться открытым — это и есть бот. Остановить его — `Ctrl + C`.

**Чтобы Mac не засыпал.** Пока бот работает, он сам не даёт системе уснуть (экран при этом
может гаснуть). Но ноутбук с закрытой крышкой всё равно уснёт — держите его открытым
и на зарядке.

**Чтобы бот запускался сам после включения Mac:** дважды кликните `autostart-mac.command`
(или запустите его через Терминал так же, как `start.command`). После этого при входе в систему
окно с ботом будет открываться само. Запустите файл ещё раз — автозапуск выключится.
Чтобы после перезагрузки Mac не ждал пароля, включите автоматический вход
(«Системные настройки» → «Пользователи и группы» → «Автоматический вход»).

Случайно запустить бота дважды не страшно: второе окно сообщит, что бот уже работает.

## Запуск на Windows

1. **Установите Python 3.13**: <https://www.python.org/downloads/windows/>. При установке
   обязательно поставьте галочку **Add python.exe to PATH**.
2. **Скачайте папку `stock-bot`**, например в `C:\stock-bot`.
3. **Дважды кликните `start.bat`**. При первом запуске он сам установит всё нужное
   и попросит вставить токен.
4. Откройте бота в Telegram и нажмите **«Старт»**.

Чёрное окно должно оставаться открытым. Автозапуск: `Win + R` → `shell:startup` → положите
туда ярлык на `start.bat`. Спящий режим отключите в «Параметры → Система → Питание».

На Linux: `bash start.command`.

## Как пользоваться

1. Пришлите боту ссылку на **вашу таблицу**. В Google Таблице должен быть открыт доступ
   «Все, у кого есть ссылка — читатель». Бот покажет, какие пометки поставщиков он видит
   в названиях и сколько вещей с каждой.
2. По одной присылайте ссылки на **таблицы поставщиков** и выбирайте пометку из списка.
3. Всё. Дальше бот проверяет таблицы сам (по умолчанию каждые 10 минут, меняется в настройках).

| Кнопка | Что делает |
|---|---|
| 📦 Мои вещи | за чем слежу и что сейчас в наличии; разбор спорных вещей; исправление привязок |
| 🔎 Поиск по базе | поиск по размерам и названиям во всех таблицах поставщиков |
| 📊 Таблицы | список таблиц, как бот понял каждую, изменить пометку, удалить |
| 📋 Проверить наличие | список ваших выставленных вещей, которых нет у поставщиков, — чтобы снять их с Авито |
| ⚙️ Настройки | как часто проверять; выключить сообщения о цене, новых размерах и т. п. |

### О чём бот пишет

- убрали размер — и что осталось сейчас; отдельно, если остался один размер;
- вещь закончилась или снова появилась;
- появились размеры;
- осталась 1 штука (если поставщик указывает количество);
- изменилась цена;
- вещь пропала из таблицы или её переименовали;
- таблица поставщика перестала открываться (после трёх неудач подряд, без спама).

## Какие таблицы он читает

- **Google Таблицы по ссылке** — основной способ. Бот читает только текст, без фотографий,
  поэтому таблицы на сотни мегабайт с картинками проверяются за секунду.
- **Excel-файлы** (.xlsx, .xls) и CSV — файл можно прислать боту. Такая таблица сама
  не обновляется: когда поставщик пришлёт новый файл, перешлите его боту и нажмите «Обновить».
- **Яндекс Диск** — публичная ссылка на файл или папку (возьмёт самый свежий файл).

Форматы внутри таблицы бот распознаёт сам:

- размеры одной ячейкой: `S M XL XXL`, `S, M, L`, `S-2, M-1`, `-` (нет в наличии);
- размеры по столбцам с количеством: `0`, `15`, `много` (в том числе объединённой ячейкой
  на несколько размеров), `✅` / `❌`, `+` / `-`;
- отдельный блок на каждую вещь со своей шапкой;
- по строке на размер со столбцом остатка; зачёркнутые размеры в Excel считаются проданными;
- вещи без размеров: `есть` / `нет`.

Если бот понял таблицу неправильно: «📊 Таблицы» → таблица → «🛠 Настроить столбцы».

**Не поддерживается:** сайты-каталоги с входом по ключу (например, личный кабинет поставщика).
Попросите у такого поставщика таблицу или выгрузку в Excel.

## Если что-то не так

- **«Не могу открыть таблицу: доступ закрыт»** — откройте таблицу по ссылке для всех.
- **«Нет связи с Telegram»** — если Telegram на компьютере работает только через VPN,
  включите VPN или впишите HTTP-прокси в файл `.env` (строка `TELEGRAM_PROXY`).
  Бот будет пробовать подключиться снова каждые 10 секунд.
- **Mac пишет, что файл нельзя открыть** — запустите его через Терминал, как в шаге 3:
  после первого такого запуска двойной клик начнёт работать.
- **«Telegram не принял токен»** — запустите ещё раз, бот спросит токен заново.
- **Бот не нашёл пару для вещи** — проверьте, что в названии есть пометка поставщика,
  и выберите вещь вручную в «📦 Мои вещи».
- У поставщика несколько вещей с одинаковым названием и без ссылок на фото — бот не может
  их различить и показывает общее наличие, о чём пишет в сообщении.

Все данные бота лежат в папке `data` рядом с ним (база и журнал `bot.log`). Токен — в файле
`.env`; никому его не показывайте.

## Для разработчика

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/python -m pytest        # 84 теста: разбор таблиц, сопоставление, сценарии бота
.venv/bin/python -m stockbot      # запуск
```

| Файл | Назначение |
|---|---|
| `stockbot/sizes.py` | распознавание размеров и отметок наличия |
| `stockbot/workbook.py`, `gsheets.py` | чтение Excel / CSV и веб-версии Google Таблиц |
| `stockbot/parser.py` | лист → список товаров с размерами |
| `stockbot/matching.py` | пометки поставщиков, сопоставление названий, поиск |
| `stockbot/engine.py` | цикл проверки и поиск изменений |
| `stockbot/bot.py` | диалоги в Telegram |
