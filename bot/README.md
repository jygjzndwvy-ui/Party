# Бот: следит за ценами и пишет в Telegram

Раз в 30 минут открывает страницы товаров из `config.json`, запоминает цену и присылает сообщение
в Telegram, когда цена упала на заданный процент (по умолчанию 5%). Работает бесплатно в GitHub Actions,
свой сервер не нужен.

## Настройка (один раз)

1. **Создайте бота.** В Telegram напишите [@BotFather](https://t.me/BotFather) команду `/newbot`,
   придумайте имя. В ответ придёт токен вида `1234567890:AA...`.
2. **Напишите своему боту любое сообщение** (например, «привет») — без этого он не сможет писать вам первым.
3. **Узнайте свой chat id.** Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найдите число в `"chat":{"id":...}`.
4. **Сохраните секреты в GitHub.** В репозитории: Settings → Secrets and variables → Actions →
   New repository secret. Нужны два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1;
   - `TELEGRAM_CHAT_ID` — число из шага 3.
5. **Добавьте товары** в `config.json` (см. ниже).
6. **Перенесите всё в основную ветку репозитория.** GitHub запускает расписание только из основной ветки.
7. Проверка: вкладка Actions → Price bot → Run workflow. На каждый новый товар бот сразу пришлёт
   сообщение «Начал следить за ценой».

## Как добавить товары

```json
{
  "dropPercent": 5,
  "currency": "RUB",
  "products": [
    { "url": "https://shop.example/product/123" },
    {
      "name": "Кроссовки, размер 42",
      "url": "https://another.example/item/456",
      "dropPercent": 15,
      "selector": ".product-price__current"
    },
    { "url": "https://js-shop.example/p/789", "selector": ".price", "render": true }
  ]
}
```

| Поле | Обязательно | Что значит |
|---|---|---|
| `url` | да | Ссылка на страницу товара |
| `name` | нет | Название в сообщениях. Если не указать, бот возьмёт заголовок страницы |
| `dropPercent` | нет | На сколько процентов должна упасть цена. Без него действует общий `dropPercent` |
| `selector` | нет | CSS-селектор элемента с ценой, если бот сам её не находит |
| `render` | нет | `true` — открывать страницу в настоящем браузере. Для сайтов, где цена появляется только после загрузки скриптов. Проверка идёт на 1–2 минуты дольше |
| `currency` | нет | Валюта, если магазин её не указывает (`RUB`, `USD`, `EUR`…) |

Большинство магазинов бот читает сам: цена берётся из стандартной разметки страницы
(schema.org JSON-LD, meta-теги, microdata). Если цена не нашлась, укажите `selector`:
в браузере нажмите правой кнопкой на цену → «Просмотреть код» и возьмите класс элемента.

## Как бот решает, что цена упала

- Падение считается от цены на момент прошлого сообщения. Мелкие снижения копятся: 3% сегодня и 3% завтра
  вместе дадут сообщение при пороге 5%.
- Если цена выросла, дальше падение считается от новой, более высокой цены. Чтобы не попасться на
  «скидку» после накрутки, в каждом сообщении указан минимум за всё время наблюдения.
- Если страница не читается 6 проверок подряд (около 3 часов), бот один раз об этом предупредит.

## Ограничения

- Крупные маркетплейсы (Ozon, Wildberries, Авито) защищаются от автоматических запросов и с серверов GitHub,
  скорее всего, читаться не будут. Бот рассчитан на обычные интернет-магазины.
- Расписание GitHub неточное: в часы пик запуск может задержаться на 10–20 минут.
- В приватном репозитории каждая проверка тратит около минуты из бесплатных 2000 минут Actions в месяц
  (при 30-минутном интервале — примерно 1500). Интервал меняется в `.github/workflows/price-bot.yml`, строка `cron`.
- История цен хранится в кэше Actions. Если бот не запускался больше 7 дней, она стирается,
  и наблюдение начнётся заново.

## Запуск на своём компьютере

```bash
cd bot
npm ci
npm test                          # тесты разбора цен
DRY_RUN=1 node check.mjs          # проверить цены, сообщения показать в консоли и не отправлять
TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... node check.mjs
```

Для товаров с `"render": true` дополнительно нужны `npm install --no-save playwright` и
`npx playwright install chromium`.
