# Бот для NFT-подарков Telegram: этап 1

Бот следит за рынком перепродажи подарков внутри Telegram, ищет лоты дешевле похожих
и **торгует понарошку** («бумажная торговля»), чтобы проверить, работают ли правила,
прежде чем рисковать настоящими TON.

**Что бот делает сейчас:**
- просматривает лоты на маркете Telegram через официальный API;
- оценивает ваши подарки: редкость, красивый номер, цены похожих лотов, оценка самого Telegram;
- находит выгодные лоты по правилам из статьи и присылает их вам в «Избранное»;
- ведёт бумажные сделки: «покупает», «выставляет», снижает цену, «продаёт» и считает итог.

**Чего бот не делает:** не покупает, не продаёт, не выставляет и не передаёт подарки.
В этой версии таких функций нет совсем: в `giftbot/telegram_api.py` только запросы на чтение.

## Безопасность

- В папке `private` после входа лежат `api_id`, `api_hash` и сессия Telegram. **Это ключ к вашему
  аккаунту.** Никому их не отправляйте: ни людям, ни Claude, ни «поддержке».
- Если файлы могли утечь: Telegram → Настройки → Устройства → завершите лишний сеанс.
- Бот делает не больше одного запроса в 1,5 секунды, чтобы Telegram не ограничил аккаунт.

## Быстрый запуск на Mac

1. Дважды кликните **`login.command`**. Он сам установит всё нужное, спросит `api_id` и `api_hash`
   (как их получить, написано в шаге 5 ниже) и откроет в браузере QR-код. Отсканируйте его телефоном:
   Telegram → Настройки → Устройства → «Подключить устройство».
2. Дважды кликните **`start.command`**. Бот работает, пока открыто это окно.

Папки `private`, `data` и `.venv` создаются с окончанием `.nosync`, чтобы iCloud не копировал
ключи входа и базу. Ниже описана ручная установка, например для Windows.

## Установка (один раз)

1. **Python 3.11 или новее.** Скачайте с [python.org/downloads](https://www.python.org/downloads/).
   На Windows в первом окне установщика поставьте галочку **Add python.exe to PATH**.
2. **Распакуйте** архив `gift-bot.zip`, например в «Документы».
3. **Откройте терминал в папке `gift-bot`:**
   - Windows: откройте папку в Проводнике, в адресной строке сверху напишите `cmd` и нажмите Enter.
   - macOS: откройте программу «Терминал», напишите `cd ` (с пробелом), перетащите папку
     `gift-bot` в окно терминала и нажмите Enter.
4. **Установите бота.** Вставьте команды по одной.

   Windows:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
   macOS:
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
5. **Войдите в Telegram:** `python bot.py login`
   - Бот попросит `api_id` и `api_hash`. Их выдаёт сам Telegram: откройте
     [my.telegram.org](https://my.telegram.org), войдите по номеру телефона, выберите
     «API development tools» и создайте приложение (название и описание любые).
   - Затем в браузере откроется QR-код. На телефоне откройте Telegram → Настройки → Устройства →
     «Подключить устройство» и наведите камеру на код. Если включена двухэтапная проверка,
     бот попросит пароль в терминале.
   - Вход по коду из сообщения вместо QR: `python bot.py login --code`. Бот скажет, куда Telegram
     отправил код (в приложение, по SMS или на почту). Код и пароль вводите только в своём терминале.

В следующие разы перед командами открывайте терминал в папке и включайте окружение:
`.venv\Scripts\activate` на Windows или `source .venv/bin/activate` на macOS.

## Как пользоваться

| Команда | Что делает |
|---|---|
| `python bot.py check` | Проверяет вход и показывает пример данных с маркета. Пришлите вывод Claude. |
| `python bot.py mygifts` | Оценивает ваши подарки и подсказывает цену продажи. |
| `python bot.py scan` | Один проход по рынку (несколько минут). |
| `python bot.py run` | Работает постоянно, пишет вам в «Избранное». Окно терминала не закрывайте. |
| `python bot.py report` | Итоги бумажной торговли. |

Пока работает `run`, в «Избранное» в Telegram можно написать:
- `/status`, чтобы получить сводку;
- `/stop`, чтобы остановить бота (или нажмите Ctrl+C в терминале).

Чтобы бот работал круглосуточно, компьютер не должен засыпать:
- Windows: Параметры → Система → Питание → «Переводить в спящий режим» → «Никогда» (от сети).
- macOS: Системные настройки → Аккумулятор (или «Экономия энергии») → запретить автоматический сон
  при питании от сети.

**План:** запустите `run` на 1–2 недели, затем `report`. Переходить к настоящим сделкам стоит,
только если бумажный итог в плюсе и сделок было хотя бы 10.

## Как бот решает

Правила взяты из статьи «Флип подарков в Телеграме», цифры можно поменять в `config.toml`.

1. **Сегмент.** Лот сравнивается не со всей коллекцией, а с похожими: та же модель, а для фонов
   Black и Onyx Black ещё и тот же фон. Ориентир: самый дешёвый **другой** похожий лот.
   Если сегментов несколько, берётся самый высокий ориентир.
2. **Безубыток** = цена покупки ÷ доля продавца. При продаже за TON доля 90%, за звёзды 80%:
   это видно в настройках самого Telegram (команда `check`). Дешевле 7 TON продать за TON нельзя.
3. **Покупать**, только если продажа на 3% дешевле ориентира даёт безубыток плюс 15%.
   Пример: лот за 5 TON, ориентир 8 TON. Продаём за 7,76 TON, на руки 6,98 TON, прибыль ≈ +1,98 TON.
4. **Продажа (понарошку)** засчитывается строго: наш лот был самым дешёвым в сегменте,
   а Telegram подтвердил продажу соседнего лота, который стоил не меньше нашего.
   Снятые с продажи лоты продажей не считаются.
5. **Цена снижается** раз в сутки на 5%, но не ниже безубытка. Через 7 дней без продажи
   подарок «продаётся» по рынку, даже в минус. Так тест показывает и неудачные сделки.

## Настройки

Все настройки с пояснениями лежат в `config.toml`. Главные:
- `bank_ton`: бюджет теста (сейчас 10 TON, столько примерно придёт на руки, если продать ваш Myth Mask за ~11,15 TON);
- `max_buy_ton`: самая высокая цена одной покупки;
- `seller_share_ton`: доля продавца. Сверьте с суммой «на руки» в окне продажи Telegram;
- `min_margin`: запас над безубытком;
- `collections`: смотреть только выбранные коллекции.

## Если что-то не так

- **my.telegram.org пишет ERROR при создании приложения.** Попробуйте позже, отключите VPN
  или откройте сайт в другом браузере.
- **«Вход в Telegram не выполнен».** Запустите `python bot.py login` ещё раз.
- **Бот пишет, что Telegram попросил подождать.** Это нормально, бот подождёт и продолжит сам.
- **Любая другая ошибка.** Пришлите Claude текст ошибки и последние строки файла `data/bot.log`.
  Файлы из папки `private` не присылайте.
