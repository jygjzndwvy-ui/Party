# Правила, чтобы не заигрываться

## 1. Бот соблюдает сам

Бот проверяет эти правила в коде перед каждой покупкой и нарушить их не может.
Числа меняются в `config.toml`. Ослаблять их стоит только после честного теста, ужесточать можно всегда.

| Правило | Сейчас | Настройка |
|---|---|---|
| Не больше одной покупки в сутки | 1 | `max_buys_per_day` |
| Не больше одного подарка одновременно | 1 | `max_open_positions` |
| **Стоп при убытке**: покупки останавливаются, пока вы сами не напишете `/resume` | 15% бюджета (1,5 TON из 10) | `stop_loss_total` |
| Пауза после убыточной сделки, чтобы не «отыгрываться» | 24 часа | `cooldown_after_loss_hours` |
| Коллекция, где был убыток, на паузе | 7 дней | `collection_cooldown_days` |
| Покупка только с запасом над безубытком | 15% | `min_margin` |
| Сравнение минимум с несколькими похожими лотами | 2 | `min_other_listings` |
| Цена не ниже безубытка; на 7-й день продажа по рынку, даже в минус | 7 дней | `max_hold_days` |
| Один и тот же лот не покупается повторно | 7 дней | — |
| Только TON: за звёзды продавцу приходит 80% вместо 90% | — | — |

Сработавший стоп бот присылает в «Избранное». Открытые сделки он продолжает продавать по правилам.

## 2. Переход к настоящим деньгам

Решаете только вы, не бот и не Claude. Настоящих покупок в боте пока нет. Встраивать их стоит,
только если выполнено всё:

- прошло не меньше 7 дней бумажной торговли;
- закрыто не меньше 10 бумажных сделок;
- итог после комиссий в плюсе, и больше половины сделок в плюс;
- вы сами написали Claude, что включаете настоящие сделки и на какую сумму.

Первые настоящие сделки только полуавтоматом: каждую покупку вы подтверждаете кнопкой.

## 3. Правила для Claude

- Никогда не покупать, не продавать, не выставлять, не передавать подарки и не выводить деньги
  без отдельного «да» пользователя на каждую операцию.
- Не просить и не принимать коды входа и пароль двухэтапной проверки. Вход только через
  `login.command` на Mac (QR-код).
- Не открывать и не пересылать файлы из папки `private`.
- Ослаблять лимиты только по прямой просьбе пользователя. Ужесточать можно, объяснив зачем.
- Говорить честно: бумажный плюс не равен настоящей прибыли, убытки показывать так же, как прибыль.
- Перед изменением кода запускать тесты. Основная копия кода: репозиторий Party,
  ветка `claude/relaxed-dirac-p2nghf`, папка `gift-bot`.

## 4. Правила для вас

- Торгуйте только теми деньгами, которые не жалко потерять.
- «Подключи кошелёк, чтобы забрать подарок» — это кража кошелька. Скриншот оплаты — не оплата.
  «Переведи первым» — нет.
- Не гонитесь за ценой и не «отыгрывайтесь» после минуса. Для этого и есть паузы выше.
