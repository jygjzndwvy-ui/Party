# TROPICAL QUEST™ — Hawaiian Birthday Adventure

Цифровой набор для детского дня рождения в гавайском стиле (6–10 лет, 2,5–3 часа, дома или во дворе).
Набор продаётся как готовый к печати продукт.

## Что лежит в `dist/` (это и есть товар)

| Файл | Что это |
|---|---|
| `TROPICAL_QUEST_1_Гид_организатора.pdf` | 35 страниц: концепция, легенда, персонажи, тайминг, сценарий ведущего, 9 игр, квест, HOME/GARDEN, меню и рецепты, список покупок, декор, музыка, печать, дипломы, подарки, подготовка, безопасность, лицензия |
| `TROPICAL_QUEST_2_Printable_Kit.pdf` | 38 страниц для печати: приглашения, постер, баннер ALOHA, бейджи, корона, письмо Пико, карта, жетоны, карточки игр, таблички, топперы, этикетки, фотобутафория, дипломы, 12 номинаций, бирки Mahalo, раскраска |
| `TROPICAL_QUEST_набор_для_покупателя.zip` | оба PDF одним архивом — то, что отправляется покупателю |
| `avito/01.jpg … 08.jpg` | 8 картинок для объявления (1600×1200, 4:3) |
| `Авито_текст_объявления.txt` | название, описание и ключевые слова для объявления |

## Пересборка и персонализация

Нужны Node.js 18+, Playwright (Chromium) и `pdftoppm` (poppler-utils).

```bash
node src/build.mjs                                   # обычная версия (поля для имени — пустые строки)
node src/build.mjs --name "Маша" --age 7             # именная версия: имя/возраст на приглашениях, постере, дипломе вождя, бирках
node src/build.mjs --brand "Мой магазин"             # своё название в копирайте и лицензии
node src/build.mjs --only guide|kit|avito            # собрать только одну часть
```

Именная версия сохраняется с суффиксом имени, например `TROPICAL_QUEST_2_Printable_Kit_Маша.pdf` —
её можно продавать как платную персонализацию.

## Исходники

- `src/art.mjs` — авторские SVG-иллюстрации (пальма, волна, ананас, гибискус, кокос, попугай Пико, сундук, листья, животные)
- `src/parts.mjs` — карта сокровищ, планы зон, тропические рамки
- `src/guide.mjs` — тексты и вёрстка гида организатора
- `src/kit.mjs` — страницы Printable Kit
- `src/avito.mjs` — слайды для Авито
- `src/fonts/` — шрифты Unbounded, Nunito, Caveat, Pacifico (SIL Open Font License)
