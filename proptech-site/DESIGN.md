# Дизайн-система

Направление выбрано без подбора по библиотеке реальных сайтов (UXKIN не был подключён):
оно выведено из самой темы и описано ниже. Все значения живут в `src/assets/css/01-tokens.css`,
в коде используются только имена токенов.

## Идея: свет в окне

Агентство без офиса встречает клиента не в кабинете, а в его будущем доме. Отсюда образ:
вечерний город в «синий час» и тёплый свет в окнах. Он задаёт всё остальное.

- **Холодные сине-серые нейтральные**: небо, бетон, стекло.
- **Один тёплый акцент, янтарный**: свет в окне. Янтарным горит только то, что активно или доступно:
  главная кнопка, выбранный фильтр, текущий шаг сделки, объект с онлайн-показом.
- **Знак логотипа**: окно из четырёх створок, одна горит. Четыре створки это четыре сервиса;
  тот же приём повторяет блок сервисов на главной.

## Цвет

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#EEF2F6` | Фон страницы, «бетон» |
| `--bg-raised` | `#FFFFFF` | Карточки |
| `--bg-sunken` | `#E0E7EE` | Поля форм, подложки |
| `--text` | `#101B2D` | Основной текст |
| `--text-2` | `#44536A` | Вторичный текст |
| `--text-3` | `#62728A` | Подписи |
| `--accent` | `#FFC145` | Кнопки и активные состояния |
| `--accent-ink` | `#101B2D` | Текст на акценте |
| `--accent-text` | `#8A5800` | Янтарный текст на светлом фоне |
| `--night-900` | `#0C1626` | Тёмные секции, подвал |
| `--ok` / `--err` | `#1C9A69` / `#D2463F` | Успех и ошибка |

Тёмная тема (`data-theme="dark"`) переопределяет роли: фон `#0C1626`, карточки `#122036`, текст `#EEF3F8`.
Контраст основного текста не ниже 4,5:1 в обеих темах.

Закатный градиент неба (тёмно-синий → сиреневый → персиковый) используется только в сценах:
на первом экране, в шапках разделов и в блоке заявки. В интерфейсе градиентов нет.

| Роль | Шрифт | Размер | Начертание |
|---|---|---|---|

| H1 | Geologica | 36–72 px | 600 |
| H2 | Geologica | 30–56 px | 600 |
| H3 | Geologica | 22–32 px | 600 |
| Лид | Geologica | 17–21 px | 300 |
| Текст | Geologica | 16 px | 350 |
| Подписи и метки | JetBrains Mono | 11–12 px | 500, прописные, трекинг 0,06em |

Geologica: геометрический гротеск с характерной кириллицей, хорошо держит крупные заголовки.
JetBrains Mono отдан «техническим» подписям: номера шагов, метки, площади, как пометки на чертеже.
Заголовки балансируются по строкам (`text-wrap: balance`), длинных тире в текстах нет.

## Отступы и форма

- Шаг 4 px: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128.
- Секция: `clamp(72px, 10vw, 152px)`. Контейнер 1280 px, поля `clamp(16px, 4vw, 48px)`.
- Радиусы: 6 / 10 / 16 / 24 / 36 px и «пилюля» для кнопок.
- Тени две: `--shadow-1` для карточек, `--shadow-2` для всплывающих и главных блоков. Янтарное свечение `--glow` только у активных элементов.

## Компоненты

Кнопки (основная янтарная, тёмная, контурная, тихая), ссылка со стрелкой, метки, чипы, сегмент со
скользящим индикатором, поля и ползунки, тумблер, карточка объекта, аккордеон, модальное окно,
всплывающее сообщение, форма заявки и форма-опрос, шаги, сетка преимуществ, сравнение.
Все лежат в `03-components.css` и `06-sections.css`.

## Движение

Движение рассказывает о продукте, а не украшает страницу. Крупных моментов четыре:

1. **Сцена «свет в окнах»** (`scene.js`). Небо рисуется на canvas, окна домов загораются по одному,
   реагируют на курсор. При прокрутке закат переходит в ночь. У окон всплывают подписи со статусами сделок.
2. **Четыре створки сервисов.** Створка «загорается» кругом из точки, куда вошёл курсор.
3. **Сделка в телефоне.** Липкий телефон слева, шаги справа: активный шаг переключает экран, линия прогресса заполняется.
4. **3D-тур** (`tour.js`). Комната на CSS 3D, которую можно крутить мышью, пальцем и стрелками; мини-план показывает направление взгляда.

Мелкие моменты: заголовки выезжают по словам, блоки появляются при прокрутке, числа «набегают»,
кнопки-магниты, метка у курсора, бегущая строка ускоряется с прокруткой, карточки каталога плавно
переставляются при фильтрации, код замка «прокручивается», подпись документа рисуется линией,
тёмная тема расходится кругом от кнопки, страницы сменяются плавным переходом.

| Токен | Значение | Где |
|---|---|---|
| `--ease-out` | `cubic-bezier(.16, 1, .3, 1)` | Появления, перемещения |
| `--ease-spring` | `cubic-bezier(.34, 1.56, .64, 1)` | Мелкие «пружинящие» отклики |
| `--d-1…4` | 180 / 320 / 600 / 950 мс | От отклика на нажатие до крупных появлений |

При `prefers-reduced-motion: reduce` анимации отключаются, сцена рисует один статичный кадр.

## Изображения и иконки
