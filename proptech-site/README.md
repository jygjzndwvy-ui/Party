# Шаблон сайта цифрового агентства недвижимости

Готовый сайт-шаблон для proptech-агентства: вся сделка онлайн, от 3D-тура до регистрации в Росреестре.
Сейчас в нём демо-название, демо-объекты и примерные условия. Замените их своими, и сайт готов к запуску.

**Что внутри**

| Страница | Файл | Что на ней |
|---|---|---|
| Главная | `index.html` | Сцена «свет в окнах», быстрый поиск, 4 сервиса, сделка по шагам, демо 3D-тура, показ по коду, проверка объекта, скоринг, вопросы, заявка |
| Купля-продажа | `kuplya-prodazha.html` | Переключатель «покупаю / продаю», преимущества, этапы, аудит вторичного жилья, каталог |
| Аренда | `arenda.html` | Переключатель «снимаю / сдаю», онлайн-заселение, скоринг жильцов и собственников |
| Займ под залог | `zaym-pod-zalog.html` | Калькулятор, оговорка «мы брокер», скоринг заявки, форма-опрос |
| Срочный выкуп | `srochnyy-vykup.html` | Оценка выкупа, ситуации, сравнение с обычной продажей, форма-опрос |
| Каталог | `catalog.html` | Фильтры, сортировка, вид плиткой и списком, ссылка сохраняет фильтры |
| Объект | `object-<id>.html` | Галерея, 3D-тур, планировка, запись на показ, отчёт о проверке, похожие |
| Личный кабинет | `cabinet.html` | Демо: вход по коду, избранное, показы, ход сделки, платежи, документы |
| Служебные | `policy.html`, `404.html` | Заготовка политики конфиденциальности и страница «не найдено» |

## Как запустить

Нужен только [Node.js](https://nodejs.org) версии 18 или новее. Устанавливать ничего не надо.

```bash
cd proptech-site
node build.mjs            # собрать сайт в папку dist/
node build.mjs --serve    # собрать и открыть на http://localhost:4173, пересборка при правках
```

Готовый сайт лежит в `dist/`. Это обычные HTML, CSS и JS: папку можно выложить на любой хостинг
или открыть `dist/index.html` двойным кликом.

## Что заполнить

Все тексты и данные лежат в папке `content/`. Разметку и стили трогать не нужно.

| Файл | Что в нём |
|---|---|
| `content/site.mjs` | Название, город, телефон, почта, мессенджеры, реквизиты, меню, условия калькуляторов, адрес для заявок |
| `content/objects.mjs` | Объекты каталога (описание полей вверху файла) |
| `content/home.mjs` | Тексты главной страницы |
| `content/services.mjs` | Тексты четырёх разделов |

Всё, что нужно поменять в первую очередь, помечено в файлах словом **ЗАМЕНИТЬ**.

**Чек-лист перед запуском**

- [ ] Название, телефон, почта, мессенджеры и реквизиты в `content/site.mjs`
- [ ] Условия займа (`loan`) и выкупа (`buyout`): ставка, доля от стоимости, сроки, проценты
- [ ] Свои объекты в `content/objects.mjs` вместо демо
- [ ] Адрес для заявок `forms.endpoint` (см. ниже)
- [ ] Текст политики конфиденциальности в `src/pages/misc.mjs`
- [ ] Тексты раздела «Займ под залог» согласованы с юристом
- [ ] `demo: false` в `content/site.mjs`: пометки «демо» и «пример» исчезнут
- [ ] Счётчик Яндекс Метрики и уведомление о файлах cookie

### Фото вместо иллюстраций

Пока у объекта пустое поле `photos`, сайт сам рисует иллюстрации интерьера. Положите фотографии
в `src/assets/img/` и перечислите их:

```js
photos: ['assets/img/1001-1.jpg', 'assets/img/1001-2.jpg'],
```

Карточка и галерея начнут показывать фото. Чтобы папка `img` попадала в сборку, добавьте в `build.mjs`
строку копирования рядом со шрифтами: `await fs.cp(path.join(SRC, 'assets/img'), path.join(OUT, 'assets/img'), { recursive: true });`

### Настоящий 3D-тур

На сайте работает демо-тур на иллюстрациях. Когда отснимете объект (Matterport или панорамы 360°),
впишите ссылку для встраивания в поле `tourUrl` объекта: вместо демо появится настоящий тур.

```js
tour: true, tourUrl: 'https://my.matterport.com/show/?m=XXXXXXXXXXX',
```

## Заявки и CRM

Каждая форма на сайте отправляет заявку POST-запросом в формате JSON на адрес из `forms.endpoint`.
Пока адрес пустой, формы работают в демо-режиме: показывают «заявка принята» и пишут заявку в консоль браузера.

Подойдёт входящий вебхук Битрикс24, Home CRM, Joy Work или собственный обработчик. Пример заявки:

```json
{
  "type": "loan",
  "page": "zaym-pod-zalog.html",
  "fields": { "name": "Анна", "phone": "+7 (900) 123-45-67", "pledge": "flat", "urgency": "now", "sum": "3000000" },
  "score": 87,
  "utm": { "utm_source": "yandex", "utm_campaign": "zalog", "yclid": "…" },
  "sent_at": "2026-01-01T10:00:00.000Z"
}
```

- **`type`** показывает, откуда заявка: `buy`, `rent`, `loan`, `buyout`, `showing` (запись на показ), `callback`.
- **`score`** это лид-скоринг: оценка «горячести» заявки от 0 до 100. Правила простые и лежат
  в `src/assets/js/core.js`, функция `leadScore`. Меняйте баллы под свою воронку.
- **`utm`** рекламные метки. Сайт запоминает их при входе, поэтому в CRM видно, с какого объявления
  Яндекс Директа пришёл клиент.

## Что подключается отдельно

Шаблон закрывает витрину и интерфейс. Для полноценной работы потребуется серверная часть:

| Задача из плана | Что уже есть в шаблоне | Что подключить |
|---|---|---|
| Каталог и CRM | Каталог с фильтрами читает `content/objects.mjs` | Выгрузку объектов из CRM в этот файл (или в JSON) и автопубликацию на доски объявлений со стороны CRM |
| Личный кабинет | Интерфейс и демо-сценарии | Вход по SMS, хранение сделок, документов и платежей на сервере |
| 3D-туры | Демо-тур и место под iframe | Съёмку Matterport или панорамы 360° |
| Показ по коду | Запись на показ, экран с кодом | Кодовые замки с API и выдачу одноразовых кодов |
| Онлайн-заселение | Сценарий, экраны договора и автоплатежа | Электронную подпись, эквайринг с рекуррентными платежами, договор со страховой |
| Скоринг | Экран с оценкой и лид-скоринг заявок | Сервисы кредитного и антифрод-скоринга, бюро кредитных историй |
| Проверка объекта | Экран отчёта | Источники данных: ЕГРН, суды, приставы, банкротства |
| Карта | Схема-заглушка на странице объекта | Виджет Яндекс Карт |
| Маркетинг | Отдельные посадочные страницы под «срочный выкуп», «деньги под залог», «купить/снять», сбор UTM-меток | Яндекс Метрику и кампании в Яндекс Директе |

## Юридически важное

- **Займы.** Агентство работает как брокер и само деньги не выдаёт. Оговорка об этом стоит в подвале
  каждой страницы и в разделе «Займ под залог». Реклама финансовых услуг регулируется законом
  «О рекламе»: тексты раздела и объявлений согласуйте с юристом.
- **Персональные данные.** У каждой формы есть неотмеченная по умолчанию галочка согласия и ссылка на политику.
  Сам текст политики сейчас заготовка.
- **Цифры.** Ставки, проценты выкупа и сроки в шаблоне примерные. Не запускайте рекламу, пока не замените их реальными.

## Как устроен проект

```
proptech-site/
├── content/            ← тексты и данные (заполняете вы)
├── src/
│   ├── pages/          ← шаблоны страниц
│   ├── partials/       ← шапка, подвал, общие блоки
│   ├── lib/            ← иконки, иллюстрации, типограф
│   └── assets/
│       ├── css/        ← стили; файлы склеиваются по номерам в app.css
│       ├── js/         ← скрипты (без зависимостей)
│       └── fonts/      ← Geologica и JetBrains Mono (лицензия OFL)
├── dist/               ← готовый сайт (создаётся сборкой)
├── build.mjs           ← сборка
├── DESIGN.md           ← дизайн-система: цвета, шрифты, движение
└── README.md
```

При сборке ко всем текстам применяется типограф: короткие предлоги не остаются в конце строки,
числа не отрываются от единиц измерения.

## Движение и доступность

- Все анимации отключаются, если у посетителя включена настройка «уменьшить движение».
- Без JavaScript страницы остаются читаемыми: скрытые до анимации блоки показываются сразу.
- Сайтом можно пользоваться с клавиатуры: видимый фокус, ссылка «к содержимому», стрелки в галерее и 3D-туре.
- Тёмная тема включается кнопкой в шапке: «ночь» расходится кругом от кнопки.
